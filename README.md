# Моя полка

Личное веб-приложение (PWA) для iPhone: полка со всем, что я уже прочитала — книги, комиксы,
манга, манхва, маньхуа, ранобэ. Данные хранятся только на телефоне.

Сайт: https://sezimesenalieva.github.io/My-shelf/

## Технологии

- [Vite](https://vite.dev) — сборщик: превращает исходники в готовый сайт.
- [React](https://react.dev) + [TypeScript](https://www.typescriptlang.org) в строгом режиме.
- [ESLint](https://eslint.org) — ищет ошибки в коде, [Prettier](https://prettier.io) — выравнивает оформление.
- [Vitest](https://vitest.dev) — юнит-тесты, [Playwright](https://playwright.dev) — e2e-тесты в браузере
  с экраном iPhone (движок WebKit, как в Safari).

## Запуск на компьютере

Нужен Node.js 22 или новее.

```bash
npm install        # установить зависимости (один раз)
npm run dev        # открыть приложение на http://localhost:5173/My-shelf/
```

## Полезные команды

| Команда             | Что делает                                                  |
| ------------------- | ----------------------------------------------------------- |
| `npm run build`     | собрать сайт в папку `dist`                                 |
| `npm run preview`   | открыть собранный сайт на http://localhost:4173/My-shelf/   |
| `npm run lint`      | проверить код линтером                                      |
| `npm run format`    | привести оформление кода к единому виду                     |
| `npm run typecheck` | проверить типы TypeScript                                   |
| `npm test`          | запустить юнит-тесты                                        |
| `npm run test:e2e`  | запустить e2e-тесты (нужен `npx playwright install webkit`) |

## Деплой

Сайт публикуется на GitHub Pages автоматически через GitHub Actions
(файл `.github/workflows/ci.yml`):

1. На каждый pull request запускаются проверки: линтер, типы, юнит- и e2e-тесты.
   Сливать pull request стоит только с зелёной галочкой.
2. После слияния в ветку `main` сайт сразу собирается и публикуется (тесты не повторяются —
   они уже прошли в pull request). Меньше чем через минуту новая версия доступна по ссылке выше.

Настройка, которую нужно сделать один раз: **Settings → Pages → Build and deployment → Source:
GitHub Actions**.

Ветка по умолчанию в репозитории — `main` (Settings → General → Default branch): GitHub Pages
публикует сайт только из неё.

### Необязательный ключ Google Books

Без ключа Google Books часто отвечает «превышена квота», и поиск работает через Open Library и
AniList. Если создать ключ (с ограничением по сайту `https://sezimesenalieva.github.io/*` и только
для Books API), его можно добавить в **Settings → Secrets and variables → Actions → Variables**
под именем `GOOGLE_BOOKS_KEY`. В коде ключа нет — он подставляется только при сборке.

Внизу экрана показывается время сборки — по нему на телефоне видно, что открылась свежая версия.

## Структура папок

```
src/
  app/        корень приложения: заголовок, пустая полка, переключение экранов
  domain/     запись, типы изданий, определение типа, дубликаты, цвета, размеры корешков
  storage/    база IndexedDB (Dexie) и репозиторий — единственный вход к данным
  covers/     обложки: показ, заглушки, сохранение копии и цвет корешка
  sources/    адаптеры каталогов (FantLab, Open Library, Google Books, AniList) и общий поиск
  features/   экраны: shelf (шкаф с корешками), list (список), card (карточка с обложкой
              и анимацией «корешок → обложка»), search (поиск и подтверждение), add (вручную)
  ui/         общие элементы: панель снизу (Sheet)
  i18n/       все тексты интерфейса (ru.ts)
  styles/     общие стили и цвета светлой и тёмной темы
tests/e2e/    e2e-тесты Playwright
docs/         заметки по проекту (например, проверка источников данных)
```

## Где хранятся данные

Только на телефоне, в IndexedDB — базе данных, встроенной в браузер. Сервера нет.
Экраны работают с данными через `src/storage/repository.ts`, поэтому позже можно добавить
синхронизацию, не переписывая интерфейс.
