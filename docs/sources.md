# Проверка источников данных (шаг 2)

Дата проверки: 15.11.2026. Запросы отправлялись из настоящего браузера (Chromium) со страницы
`http://localhost:5173`, то есть так же, как их будет отправлять приложение.

**Что такое CORS, простыми словами.** Браузер по умолчанию не даёт сайту читать ответы
с чужих сайтов. Чужой сайт может разрешить это заголовком `Access-Control-Allow-Origin`.
Если заголовка нет, наше приложение не получит ни данные, ни картинку в виде файла
(картинку можно только _показать_ через `<img>`, но не сохранить и не посчитать её цвет).

## Open Library

- Запрос: `GET https://openlibrary.org/search.json?q=...&fields=key,title,author_name,first_publish_year,cover_i,number_of_pages_median,subject`
- «Мастер и Маргарита» → `Мастер и Маргарита`, `Михаил Булгаков`, 1966, обложка есть, 439 стр. ✅ (критерий приёмки)
- «One Piece» → `ONE PIECE 1`, `尾田栄一郎`, темы `form:manga`, `form:graphic novel`.
  Значит, мангу можно узнать и здесь по темам, а не только комиксы.
- «Solo Leveling» → корейские издания (`나 혼자만 레벨 업`), английских почти нет.
- Обложка: `covers.openlibrary.org/b/id/{cover_i}-M.jpg` → перенаправление на `archive.org` →
  ещё одно перенаправление на сервер вида `ia800505.us.archive.org`. На первых двух шагах
  заголовок `Access-Control-Allow-Origin: *` есть. Последний сервер каждый раз разный, и в моей
  облачной песочнице его не открыть, поэтому окончательно проверим на телефоне на шаге 5.
  Если не получится — хранится только ссылка (как и написано в ТЗ).

## AniList

- Запрос: `POST https://graphql.anilist.co` (GraphQL), ключ не нужен.
- «One Piece» → `One Piece`, формат `MANGA`, страна `JP` → **Манга** ✅
- «Solo Leveling» → `Solo Leveling`, `MANGA`, `KR` → **Манхва** ✅
- «The King's Avatar» → `The King's Avatar`, `MANGA`, `CN` → **Маньхуа** ✅
- «Мастер и Маргарита» → пусто (так и должно быть).
- Ранобэ в AniList тоже имеют тип `MANGA`, но формат `NOVEL` (например, «One Piece: Ace's Story»).
- Обложки с `s4.anilist.co` скачиваются, CORS есть. Бонус: AniList сам отдаёт
  «основной цвет» обложки (`coverImage.color`), можно использовать для корешка.
- Автора лучше брать из сотрудников с ролью «Story» / «Original Creator», а не просто первого.
- Ограничение: около 30–90 запросов в минуту. С задержкой 400 мс после ввода этого хватает.

## Google Books

- Запрос: `GET https://www.googleapis.com/books/v1/volumes?q=...`
- Все запросы без ключа вернули **429: Quota exceeded … Queries per day**. Квота считается не
  на нас, а на общий «анонимный» проект Google, которым пользуются все, кто ходит без ключа.
  Поэтому и с телефона Google Books может часто не отвечать.
- Картинки обложек (`books.google.com/books/content?...`) приходят **без** заголовка CORS:
  показать можно, сохранить копию и посчитать цвет — нельзя. Корешок будет цветом из названия.

### Что предлагаю

1. Оставить Google Books третьим источником «на удачу»: если он ответил 429 — молча
   показываем результаты остальных (это и так требование ТЗ).
2. Основная ставка для книг — Open Library. Критерий «Мастер и Маргарита с обложкой»
   он выполняет сам.
3. Вариант на будущее (требует вашего решения): ключ Google с ограничением «работает только
   на сайте `sezimesenalieva.github.io` и только для Books API». Такие ключи Google специально
   делает для браузерных приложений, украсть его бесполезно. Но ТЗ запрещает ключи в коде,
   поэтому по умолчанию — без ключа.
